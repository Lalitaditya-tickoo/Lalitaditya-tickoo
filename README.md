- **Uncertainty-aware architectures** for chest X-ray and fundus image analysis
- **Trustworthiness auditing** of deployed models under distribution shift
- **Anomaly-calibrated forecasting** for EEG-based seizure prediction

Multiple first-author papers currently under review at IEEE conferences (2026).
